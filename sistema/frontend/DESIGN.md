# Sistema visual

Identidade própria de um ERP de operação. A referência é a densidade do Fiori e do Carbon, a leitura de tabela do Stripe e a navegação curta do Linear. Não é cópia de nenhum deles.

## Tokens

| Token | Valor | Uso |
| --- | --- | --- |
| Fundo | `#f3f4f2` | Área de trabalho |
| Papel | `#ffffff` | Painéis |
| Tinta | `#1b2420` | Menu lateral e login |
| Texto | `#1a1d1b` | Conteúdo |
| Mudo | `#5e6560` | Rótulo e apoio |
| Linha | `#d9ddd9` | Divisão |
| Acento | `#1f6b4a` | Ação principal e item ativo |
| Aviso | `#f4efe4` | Pendência |
| Ok | `#e7f2ec` | Status concluído |
| Raio | `4px` | Painel. Campo e botão usam `2px` |
| Sombra | só no diálogo e no menu móvel | O resto é plano |
| Fonte | IBM Plex Sans 400 / 500 / 600 | 14px no corpo, 13px no menu, 22px no título |

## Componentes

Botão principal é verde escuro, 34px, sem cápsula. O secundário é branco com borda. Status é uma etiqueta retangular, não uma pílula. Lista é linha com divisória, não cartão empilhado. Baia livre tem faixa cinza; baia ocupada tem faixa verde. O menu é escuro, com o item atual marcado por uma barra à esquerda.

O cliente da API não mudou. Classe, rota, permissão e dado continuam os mesmos.
